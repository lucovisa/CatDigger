# Cat Digger
Website for the game Cat Digger.

## About the game
Cat Digger is a cooperative first person shooter with survival elements, resource gathering and exploration of procedurally generated caves. Play solo or with a team of up to four players.

The game is in active development. Release date is not announced yet.
